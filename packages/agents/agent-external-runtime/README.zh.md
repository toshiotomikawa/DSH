# @deepseek-ai/dsh-agent-external-runtime

[English](README.md) | 中文

## 概述

解析持久智能体的显式账户配置目录。

## 使用方式

在持久智能体注册表、账户和会话所有者策略之后挂载此可选 Host 插件。`bindings` 配置包含 `accountId`、`runtime`（`claude-sdk` 或 `codex-sdk`）、绝对目录 `configDirectory` 和正整数 `revision`。空配置不授予任何工具运行时访问权限，包括旧版 `owner`。绑定属于部署配置，不能由模型工具指定。修改绑定或工具登录后，应提高版本号并重新加载。

`harnessBindings.resolve(sessionId, workspace)` 从持久会话元数据解析档案，并要求其所有者与会话侧存储一致。命名账户必须仍处于活动状态。本地现存目录经规范化处理，但不会列出内容；同一账户与运行时的重复配置，以及不同所有者之间重叠的实际目录，会在服务发布前被拒绝。工作区不能与任何已配置的工具目录重叠。返回值是独立的私有 Host 数据，不得返回给工具、写入日志或放入提示词。规范目录的符号链接被重定向时，操作以 `binding_stale` 失败。

预期失败通过 `HarnessBindingError.code` 标识，不暴露文件系统路径或底层原因。配置错误阻止服务发布；激活错误不会修改绑定。修正 Host 配置或身份后，需显式重试。卸载会移除服务。

身份与所有权语义见[持久智能体](../../../docs/subsystems/persistent-agents.zh.md)。

## 模型体验

订阅配额仅由 SDK 中状态为 rejected 的 `five_hour` 或 `seven_day` 通知识别。提示性限额、身份验证错误和未知故障不会选择 API 路由。`EXTERNAL_QUOTA_EXHAUSTED` 将外部回合结算为失败，不会自动重试或转移输入、信箱回执或例程结算。

按记录存储的 `agent_external_quota` 域以所有者和持久智能体为键保存拒绝状态。只有后续激活在档案明确启用 `automaticFallback`、重新验证路由并成功释放旧句柄后，才能使用首个已保存备用模型。工具调用或部分输出禁止使用备用模型。取消或未确认的拆卸保留拒绝状态。供应商提供的正常重置时间在下次激活时到期；没有重置时间时，须先关闭活动句柄，再由可信 Host 显式清除激活服务的配额状态。原生执行开启新回合，不能接管失败回合。

### 账户工具配置

#### 模型看到的内容

外部回合通过进程内桥公布已准入的记忆、信箱、例程和表 schema。Codex 还用仅存于内存的一次性凭据，经本机回环访问同一座桥。工具路径、所有者身份和凭据都不是模型参数、提示词、历史或工具配置。`harnessBindings` 仅供可信 Host 消费者使用。

#### Token 影响

随附的假 SDK 不消耗推理 token。单独激活的备用模型使用普通原生 API 路由并产生正常 token 费用；仅保存备用模型不会启用它。

#### KV 缓存影响

不改变模型输入或前缀复用。

## 已知限制和后续工作

- 此插件通过持久激活端口发布外部 Agent。随附 SDK 只做模拟记录；只有明确同意使用备用模型后，后续激活才能选择原生 API。
- 目录分离不是操作系统隔离，也不证明供应商的登录身份。登录由官方工具负责，位于此插件之外。
- 步骤工具只包括已经准入的记忆、信箱、例程和表调用。原生文件、shell、网络、计算机使用和其他 MCP 服务器会被拒绝。没有 DSH 审批流的调用以 `permission_required` 结束，并且不打开窗口。
- Codex 通过 `127.0.0.1` 访问同一座桥。一次性凭据只留在内存和子进程环境中，不进入 URL、历史或工具配置。步骤或账户结束时桥关闭。
- 缺少此插件时激活失败，不会选择原生 API。档案界面是已保存配置的独立消费者。
- `createClaudeSdk` 是 Claude 适配器，不是随附驱动。测试注入假工厂。没有工厂时，懒加载在任何网络调用之前失败关闭。Codex 因官方隐藏进程仍未解决而保持不可用，并声明为部分实现。适配器不读取工具凭据。
