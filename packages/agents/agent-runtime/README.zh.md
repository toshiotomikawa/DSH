# @deepseek-ai/dsh-agent-runtime

将持久智能体身份连接到邮箱和例程会话。在注册表、记忆、agents 和 system-prompt 之后全局加载，在邮箱和例程服务之前加载。会话先持久绑定身份，再创建或恢复，并加载身份指令和必要记忆。例程先返回会话句柄，完成回合后异步报告结果，避免阻塞结算队列。工具的 exec.agent.id 是会话标识，桥接通过注册表解析持久身份。

此可选插件不修改默认配置，不增加额外模型调用。单用户部署中的所有智能体互相可见；ownerId 尚不参与授权。账户切换和自动备用模型切换不在范围内。
