# Persistent agents

## Summary

Optional packages that give persistent agents a stable identity, durable memory, mailbox messaging and scheduled routines. They stay opt-in and leave upstream profiles unchanged.

## Subsystem

The [persistent agents subsystem](../../docs/subsystems/persistent-agents.md) owns stable profile identities, session bindings, memory transactions and model-facing memory tools. These packages are opt-in and do not change upstream profiles.
