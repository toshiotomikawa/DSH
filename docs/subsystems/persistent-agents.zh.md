# 持久智能体

此可选能力提供 `ctx.persistentAgents` 和 `ctx.agentMemory`，不会修改上游默认配置。先加载存储、模型和会话服务，再全局加载 agent-registry、agent-memory 和 tool-agent-memory。省略的模型字段继承调用方指定的配置；主模型和备用模型都通过适配器目录验证。备用顺序、账户标签和切换同意仅保存和显示，不自动切换。

## 身份

创建操作保存稳定标识、名称、职务、描述、指令、首个任务、头像、版本和可选 ownerId，不启动模型回合。更新要求当前版本；省略字段保持不变，批量更新逐项返回结果。权限管理不在 M6a 范围内。

在智能体预设中加载 `@deepseek-ai/dsh-tool-agent-memory/preset`，配置 agentId。该行按原文注入身份和必要记忆，在激活前验证模型，并持久绑定会话。通过 metadataOf(sessionId) 读取 agentId。绑定保存在 agents 域中，不更改上游会话头或日志格式。重命名不会改变标识和已有引用。M6b/M6c 负责消息和例程。

本地头像由现有 sharp 依赖解码，接受不超过 512 KiB 的 PNG、JPEG 和 WebP。图片与生成种子不能同时提供。无效更新保留旧头像。生成头像保存稳定种子供界面渲染。

## 记忆

remember、forget 和 search_memories 从调用会话确定所属智能体。list 提供带 nextCursor 的分页。进程内按不区分大小写的词搜索，再按匹配数、更新时间和标识排序，无匹配返回空数组。记忆始终是不可信数据，不授予权限。

maxMemories 默认为 256，maxMemoryBytes 和 essentialBytes 默认为 8192 UTF-8 字节。必要上下文预算包括完整序列化数据和警告。预算不足时操作明确失败，保留原文和原有选择；调用方可明确重试保存为可搜索记忆。降低限制也不删除数据；必要上下文超限会阻止激活，直到可信调用方调整选择。selectForUser 使用版本比较更新选择，可锁定选择使模型不能更改。

更改按当前回合暂存。现有 session/event 的 turn/end 提供 completed 结果，因此仅成功回合提交，取消、失败和会话释放丢弃暂存。每个智能体的完整记忆集合为一个 per-record 记录，使多项更新通过一次原子写入提交。集合版本防止并发回合相互覆盖；跨进程协调沿用 storage-domain 的限制。

工具仅报告暂存。下一次提示组装等待已接纳的提交；提交失败会记录并向受影响会话报告一次，随后可重试。写入完成前进程崩溃可能丢失暂存更新，工具不会声称未确认的数据已持久化。消费者可调用 settled(sessionId) 等待结果。

## 验证

运行 `pnpm exec vitest run packages/agents`。Loader 测试通过 cordis.yml 加载真实插件、存储和智能体循环，仅模拟模型提供方。测试覆盖重开、验证、隔离、成功与取消回合、版本冲突、用户锁和预算限制，并对每个源文件要求 100% 覆盖率。
